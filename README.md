## 技术关键词速览

- **Agent 编排**：LangGraph 图编排、条件路由、并行工具调用、Reflection 补检循环、Agent Memory
- **RAG 全链路**：文档抽取、多策略切片、混合检索（稠密 + BM25）、RRF 融合、重排序、引用溯源
- **检索质量**：评测集构建、Recall@K / MRR 评估
- **存储与基础设施**：Qdrant、Neo4j、MongoDB、PostgreSQL、Redis、Docker、MinIO
- **推理与部署**：vLLM / Ollama / TGI / Triton、Function Calling、SSE 流式
- **语言与框架**：Python、FastAPI、SQLAlchemy、TypeScript、React
