# 基于 Agent + MCP 架构的智能病虫害识别系统

> 针对农业病虫害识别场景中**数据源分散、人工排查效率低**的问题，
> 设计「感知 - 规划 - 执行」闭环的 AI Agent 系统。
>
> **技术栈**：Agent 架构 · MCP（Model Context Protocol）· 多模态检索

---

## 架构设计

采用「**感知 - 规划 - 执行**」闭环的 Agent 架构，解决的核心问题是
**大模型与外部异构数据源之间的通信壁垒**。

基于 **MCP 协议**打通大模型与异构数据源（实时气象数据、农作物图像库、专业知识库）
的标准化通信，把底层的 HTTP 请求与数据库查询**封装为可自主调用的技能清单** ——
模型不需要知道数据从哪来、怎么取，只需要知道"有什么能力可用"。

## 核心贡献

实现**智能任务分解与工具调度模块**：

- 能把一个复合识别任务拆解为子任务并调度相应的工具
- 支持多模态检索（图像 + 文本知识）
- 插件化扩展 —— 新数据源可低成本接入

## 结果

复杂场景下识别准确率提升 **10.7%**，端到端自动化处理率达 **90%**，
相比传统单一模型方案显著降低了人工干预成本。
